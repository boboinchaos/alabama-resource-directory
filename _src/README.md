# Site tools (not part of the public pages)

The pages in this repo were generated by `build.py` from the Navigator data. These tools add
the SEO layer on top and can be re-run at any time from the repo root:

    pip install markdown
    python3 _src/seo.py

- `seo.py`: city pages, FAQs + schema, nearby counties, guides, contractor quote boxes,
  noindex rules, blog, /get-repair-quotes/, sitemap.xml, robots.txt. Paste the GoHighLevel
  repair-quote form link into `REPAIR_FORM_URL` at the top when it exists.
- `blog/*.md`: one file per guide. Front matter: title, seo_title, summary, date, needs
  (need keys: power, water, gas, plumbing, roof, food, rent, shelter, clothing, furniture,
  transport, equipment, respite, foster, health, benefits, job). New posts appear on the
  blog, on matching county pages and in the sitemap automatically.
- `adj.json`: which Alabama counties border each other (from Census county shapes).
- `parse.py`: pulls listing data back out of the built pages.

If `build.py` regenerates the site, run `seo.py` again afterwards.

## Closest-first address search (/near/)
- `assets/near.js` geocodes the visitor's address in the browser (OpenStreetMap Nominatim, ZIP fallback) and sorts programs by distance.
- Program locations: `_src/geo.json` (street-level, from the Census batch geocoder, 1,605 programs); anything not matched falls back to its ZIP center (`_src/al_zips.json`) or town center and shows "approx.".
- To re-geocode after adding programs: rebuild `_src/geocode_in.csv` (id,street,city,AL,zip), upload it at geocoding.geo.census.gov (Batch, Public_AR_Current), and merge the matched id,lat,lon into `geo.json`.
