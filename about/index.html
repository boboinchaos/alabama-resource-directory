About Alabama Resource Directory

A free, plain-language directory of help in every Alabama county, built by people who do this work every day.

We list local, state and federal programs for utility bills, food, rent, shelter, home repair, rides, medical equipment, caregiving, foster and kinship families, health care, benefits and jobs. Programs were last checked November 2026.

We don't run any of these programs, can't guarantee anyone qualifies, and funding changes often. Always call first. Found something wrong? Tell us.

Alabama Resource Directory lists free and low-cost help in all 67 Alabama counties. Programs checked November 2026. Funding opens and closes, so call to confirm before you go. We don't run these programs and can't promise eligibility.

In a crisis, call or text 988. For any local help, dial 2-1-1. Emergencies: 911.
